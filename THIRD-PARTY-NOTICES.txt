gloader Linux Native - Third-Party Notices

gloader itself is distributed under the repository's LICENSE.md.

Managed build/runtime dependencies include:

- Harmony / Lib.Harmony
  Runtime method patching library.
  Upstream: pardeike/Harmony on GitHub.

- Microsoft.CodeAnalysis.CSharp (Roslyn)
  Used to compile raw C# source mods at launch.
  Upstream: dotnet/roslyn on GitHub.

- Microsoft.NETFramework.ReferenceAssemblies
  Build-time reference assemblies used so the managed loader can target the Mono-compatible .NET Framework API surface from modern .NET SDKs.

Terraria, FNA, and the Mono runtime shipped with Terraria are NOT distributed by this repository. gloader loads the user's existing Terraria installation in place. Terraria and its bundled components remain subject to their respective owners' licenses.
